# Sample data

`orion_solar_handbook.pdf` (8 pages) and `lumen_library_policy.pdf` (6 pages) are **original, fictional
documents written for this project**. They are generated by `make_sample_pdfs.py`, so they can be
redistributed freely and regenerated at any time:

```bash
python sample_data/make_sample_pdfs.py
```

Each page covers one topic with specific numbers and dates, which is what lets
`evaluation/evaluate.py` measure page-level retrieval (Recall@k, MRR) against known answers.

`sample_questions.json` holds the questions shown as quick-start buttons in the app.

## Legally reusable PDFs for your own testing

If you want to try the assistant on real documents without licensing worries, these sources are
free to download and reuse:

| Source | Why it is safe | Example |
| --- | --- | --- |
| [Project Gutenberg](https://www.gutenberg.org/) | Public-domain books; most titles offer a PDF or can be printed to PDF | *The Art of War*, *Pride and Prejudice* |
| [arXiv](https://arxiv.org/) (CC-BY papers) | Many papers are published under Creative Commons licences (check the licence badge on the abstract page) | "Attention Is All You Need" (arXiv:1706.03762) |
| [U.S. Government publications](https://www.govinfo.gov/) | Works of the U.S. federal government are public domain | NIST AI Risk Management Framework |
| [NASA technical reports](https://ntrs.nasa.gov/) | Public domain | Any NTRS report |
| [Wikipedia "Download as PDF"](https://en.wikipedia.org/wiki/Special:DownloadAsPdf) | CC BY-SA 4.0 | Any article |

Avoid uploading confidential or copyrighted material to a public deployment.
